# Test strategy
Unit: range parser, validators, chunk coverage, scheduler fairness, token bucket, SQLite crash recovery, config parsing, CLI exit codes, privilege argument allowlist. Integration: Twisted local HTTP fixture supports 200/206/416, dropped connections, bad Content-Range, changing ETag, gzip, slow streams, corrupted bytes, proxy, timeout, mirror failover; verify SHA256/SHA512. E2E: disposable Debian 12/13, Ubuntu 24.04, Mint 22.x VMs or equivalent with real init/dpkg; install/remove a harmless test package from signed local repository; verify dpkg locks, sudo interactive/noninteractive, dry run, recovery. Benchmarks: same mirror/cache/network and versions, warm/cold runs >=5, median and p95, report native APT wins. Test artifact path evidence/{task-id}/. Commands: `python -m pytest -q tests/unit tests/integration`, `python -m pytest -q tests/e2e`, `python -m ruff check .`, `python -m mypy aptx`, `python -m build`. Do not claim tests executed unless output exists.
