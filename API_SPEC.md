# Internal API
No HTTP server. Typed interfaces in contracts/interfaces.py. `plan(action, packages, options)->Plan` resolves via python-apt, includes installed/new/removed/upgraded versions, sizes, warnings. `download(spec, policy)->DownloadHandle` publishes progress, supports pause/resume/cancel and returns VerifiedBlob only after digest matches. `execute(plan, confirmation, auth_mode)->TransactionResult` revalidates plan under native lock, elevates, runs apt-get without shell and captures exit. `history(limit,cursor)->Page`; `doctor()->Diagnostics`; `benchmark(config)->BenchmarkReport`. CLI JSON envelope: `{schema_version:1,ok:boolean,command:string,data:object|null,error:{code,message,details}|null}`. Exit 0 success, 2 usage, 3 authorization, 4 network, 5 integrity/trust, 6 APT conflict/lock, 7 partial operation/recovery required, 8 unsupported environment, 9 internal error, 130 SIGINT.
