# Runbook
`aptx doctor` reads distro, python-apt, sudo, locks, disk space, sources, cache permissions and network. On failed download inspect state/validators, resume only safe chunks; on digest mismatch quarantine/delete blob and retry trusted URI. On interrupted dpkg transaction show `sudo dpkg --configure -a` as an explicitly confirmed recovery operation through aptx repair, not automatic blind repair. Respect active locks; never delete lockfiles. Back up user SQLite and config before migration; restore only with app stopped. Escalate missing trusted metadata instead of disabling signature checks.
