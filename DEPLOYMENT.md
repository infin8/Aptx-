# Distribution and operations
Build wheels/sdist and distro-specific .deb in clean isolated CI runners. python-apt is distro-provided; do not pip-install incompatible python-apt. Debian control Depends on python3-apt, python3-twisted and compatible packaged Python dependencies or vendor only policy-approved pure-Python packages. Check distro package availability before finalizing Debian dependencies. Stage private .deb, validate installation/removal and upgrades in disposable VMs. No automatic public repository publication. Release candidate requires explicit user approval before public upload. Configuration at ~/.config/aptx/config.toml, state at ~/.local/state/aptx/, cache at ~/.cache/aptx/, system actions delegated to APT. No server infrastructure. Rollback of aptx binary via previous .deb is supported; rollback of dpkg-installed system packages is NOT atomic or guaranteed. Logs redact credentials and URLs with embedded auth.
